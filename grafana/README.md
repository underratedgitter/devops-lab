# Grafana

Open-source analytics and visualization platform for metrics, logs, and traces.

## Key Features

- **Multi-source dashboards** — query Prometheus, Loki, Elasticsearch, PostgreSQL, and more from a single dashboard
- **Rich visualizations** — graphs, heatmaps, gauges, tables, stat panels, geomap
- **Alerting** — unified alerting with multi-channel notifications
- **Template variables** — dynamic dashboards with dropdown filters
- **Provisioning** — dashboards and data sources as code (YAML/JSON)
