# 🐍 Python Utilities

Production-ready Python tools for DevOps automation, monitoring, and system administration.

## 📚 Utilities

| Utility | Description |
|---------|-------------|
| [log_analyzer.py](log_analyzer.py) | Parse log files, extract error patterns, generate summary reports |
| [health_checker.py](health_checker.py) | Check HTTP endpoint availability and response times |

## 🔜 Planned Utilities

- Disk usage analyzer with threshold alerts
- Backup verification tool
- API response monitor with historical tracking
- Service dependency checker
- JSON/YAML formatter and validator
- SSL certificate expiry checker
- DNS record auditor

## Usage

All utilities are standalone CLI tools with `argparse` interfaces:

```bash
python3 log_analyzer.py --help
python3 health_checker.py --help
```
